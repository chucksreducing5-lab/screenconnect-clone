QUICK START (3 steps):
================================================================================

1. START THE SERVER
   Linux/Mac:
     chmod +x start.sh
     ./start.sh
   
   Windows:
     start.bat
   
   Or manually:
     cd remote-support-web
     npm install
     node server.js

2. ACCESS THE SYSTEM
   Open your browser to:
   - Technician Console: http://localhost:3001/
     Login: admin / admin (CHANGE THIS IN PRODUCTION!)
   
   - Customer Landing: http://localhost:3001/customer-landing
   
   - Mobile Download:   http://localhost:3001/mobile-download

3. CREATE A SESSION
   - Login at technician console
   - Click "Generate support code"
   - Copy the customer link
   - Share with customer

DEPLOYMENT:
================================================================================

Production Setup:
  1. Change default credentials (TECH_USERNAME, TECH_PASSWORD)
  2. Obtain SSL certificate (HTTPS required for mobile)
  3. Configure PUBLIC_BASE_URL
  4. Deploy with PM2:
     pm2 start server.js --name remote-support
  5. Set up firewall and monitoring

Quick Deploy:
  - See QUICK_START.md → Production Deployment section
